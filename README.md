# 💰 Benim Finansım - Kişisel Finans Yönetim Sistemi

**Benim Finansım**, modern bir arayüz ve güçlü bir altyapı ile geliştirilmiş, kullanıcıların gelir-gider takibini, varlık portföylerini ve finansal hedeflerini tek bir merkezden yönetmelerini sağlayan bir masaüstü uygulamasıdır.

---

## ✨ Öne Çıkan Özellikler

* 📊 **Dinamik Raporlama:** Harcamalarınızı kategorilere göre pasta grafikleriyle (LiveCharts) anlık olarak analiz edin.
* 💹 **Varlık Portföyü:** Dolar, Euro, Altın ve Gümüş varlıklarınızı güncel kur bilgileriyle takip edin.
* 🔍 **Akıllı Filtreleme:** İşlem geçmişinizde başlık veya kategoriye göre gerçek zamanlı arama yapın.
* 📥 **Excel Entegrasyonu:** Tüm finansal verilerinizi tek tıkla profesyonel bir Excel dosyasına aktarın.
* 🎯 **Bütçe ve Hedefler:** Tasarruf hedefleri belirleyin ve bütçe limitlerinize yaklaştığınızda ilerlemenizi takip edin.
* 📅 **Planlanmış Ödemeler:** Gelecek faturalarınızı veya kira gibi düzenli ödemelerinizi önceden planlayın.
* 💾 **Yerel Veri Güvenliği:** Verileriniz buluta gitmez; SQLite veritabanı ile sadece sizin cihazınızda güvenle saklanır.

## 🛠️ Kullanılan Teknolojiler

* **Platform:** .NET 8.0 (WPF)
* **Veritabanı:** SQLite
* **Grafik Motoru:** LiveCharts2
* **Excel Kütüphanesi:** ClosedXML
* **UI Tasarımı:** Modern Flat UI Design

## 🚀 Kurulum ve Çalıştırma

1.  Bu depoyu klonlayın:
    ```bash
    git clone [https://github.com/kullanici_adin/BenimFinansim.git](https://github.com/kullanici_adin/BenimFinansim.git)
    ```
2.  Proje klasörüne gidin:
    ```bash
    cd BenimFinansim
    ```
3.  Gerekli paketleri geri yükleyin:
    ```bash
    dotnet restore
    ```
4.  Uygulamayı çalıştırın:
    ```bash
    dotnet run
    ```
